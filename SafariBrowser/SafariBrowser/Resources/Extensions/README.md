# Web Extensions

Place Safari Web Extension bundles (`.webextension` directories) in this folder.
They will be loaded automatically at app launch via `WebExtensionManager`.

To create an extension:
1. Use Safari Web Extension Converter or Xcode Web Extension template
2. Copy the output bundle here
3. Rebuild the app

Requires iOS 18+ and the `com.apple.developer.web-browser` entitlement.
